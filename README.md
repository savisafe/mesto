# Mesto.pro - Frontend Application

Современное веб-приложение для управления бизнесом, построенное на Next.js с интеграцией к NestJS backend API.

## 🚀 Быстрый старт

### 1. Настройка переменных окружения

Создайте файл `.env.local` в корневой директории проекта:

```env
# Backend API Configuration
NEXT_PUBLIC_API_URL=http://localhost:3000

# Application Configuration
NEXT_PUBLIC_APP_NAME=Mesto.pro
NEXT_PUBLIC_APP_URL=http://localhost:3001
```

### 2. Установка зависимостей

```bash
yarn install
```

### 3. Запуск приложения

```bash
# Убедитесь, что бэкенд запущен на порту 3000
yarn start:dev
```

Приложение будет доступно по адресу `http://localhost:3001`

## 🔧 API Integration

### Доступные endpoints

#### Авторизация
- `POST /auth/register` - Регистрация пользователя
- `POST /auth/login` - Вход по email/паролю
- `POST /auth/login/email` - Отправка ссылки для входа
- `GET /auth/login/email/{token}` - Вход по email ссылке
- `GET /auth/verify-email/{token}` - Подтверждение email

#### Бизнесы
- `GET /businesses` - Получить список бизнесов
- `GET /businesses/{id}` - Получить бизнес по ID
- `POST /businesses` - Создать новый бизнес
- `PATCH /businesses/{id}` - Обновить бизнес
- `DELETE /businesses/{id}` - Удалить бизнес

### API клиент

Все запросы к backend выполняются через централизованный API клиент (`src/lib/apiClient.ts`):

```typescript
import { apiClient } from '@/lib/apiClient';

// Пример использования
const response = await apiClient.login({
  email: 'user@example.com',
  password: 'password'
});
```

## 🐛 Troubleshooting

### Проблемы с подключением к API

1. **Ошибка подключения**:
   - Убедитесь, что backend запущен на правильном порту
   - Проверьте переменную `NEXT_PUBLIC_API_URL`
   - Проверьте CORS настройки в backend

2. **Ошибки авторизации**:
   - Проверьте настройки JWT_SECRET в backend
   - Убедитесь, что токены сохраняются в localStorage
   - Проверьте срок действия токенов (по умолчанию 7 дней)

3. **Проблемы с бизнесами**:
   - Убедитесь, что пользователь авторизован
   - Проверьте права доступа (только OWNER может создавать бизнесы)
   - Проверьте валидацию входных данных

### Частые ошибки

- **429 Too Many Requests**: Проверьте на бесконечные циклы в useEffect
- **401 Unauthorized**: Токен истек или отсутствует
- **403 Forbidden**: Недостаточно прав для выполнения операции
