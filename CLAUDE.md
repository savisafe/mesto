# CLAUDE.md

## Подключаемые инструкции

Всегда дополнительно учитывай инструкции из файлов:

- `.claude/rules/CODE_STYLE.md` — единые правила код-стиля проекта
- `.claude/rules/REVIEW.md` — критерии для code review
- `.claude/rules/MOCKS.md` — правила для mock-данных

Если инструкции в этих файлах применимы к текущему запросу, следуй им в первую очередь.

## Создание Pull Request (GitHub)

Проект размещён на GitHub (`github.com/savisafe/mesto`). Для создания PR использовать `gh`:

```bash
gh pr create \
  --base dev \
  --head <ветка> \
  --title "[<тип>]: краткое описание" \
  --body "Краткое описание на русском

Описание на русском..."
```

### Правила:

- **Название** — префикс `[<тип>]:`, где `<тип>` берётся из названия ветки (`feat`, `fix`, `hotfix`, `chore` и т.д.), затем краткое описание на английском
- **Описание** — краткое описание по-русски, что было сделано
- **Соавторство** — не указывать
- **Target branch (`--base`)** — `dev`
